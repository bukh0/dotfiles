## Subsequent audit and shortcut correction

- Super+F maximizes with the bar visible; Super+Shift+F enters true fullscreen
  with the bar hidden on that monitor. Hyprland's `hasFullscreen` includes both
  modes, so visibility checks the active workspace's client `fullscreen` mode
  (1 = maximized, 2 = fullscreen). Fullscreen events refresh client snapshots.
  Notification offsets use the same per-screen visibility helper. Existing
  Hyprland keybindings already dispatch the requested modes and were retained.
- Network commands wait for both exit and stderr completion, ignore stale text
  after failed spawn, and settle outside process callbacks before another
  command can start. Tests include delayed stream completion and immediate
  retry from a settlement listener.
- Persistent popups select only the oldest eligible cards needed by the queue;
  hovered, critical and already closing cards are excluded. Closing cards
  disable interaction, including action buttons and links.
- End scrolling now corrects its final position after delegate layout. A
  variable-height regression reproduced the old short landing and passes with
  the fix. Resizing while scrolled and deleting down to three short rows also
  shrinks correctly under both profiles; the conservative unknown-height
  fallback is retained rather than caching stale measurements across widths.
- Sysmon publishes RAM, temperature and power profile from its immediate first
  row while retaining cached CPU/network deltas until the second row. Native
  CPU and RAM percentages round to the nearest integer. The helper was rebuilt.
- Accepted Bluetooth power-off requests cancel scanning immediately; external
  adapter power-off also cancels it, and scans cannot start during power actions.
