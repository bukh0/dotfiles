# Requested fixes — 2026-09-30

Implemented the supplied review against the current configuration, preserving the newer picker, clipboard, launcher and notification changes.

## Process completion and clipboard

- Network connection results wait for both process exit and stderr completion. A nonzero mock `nmcli` secrets failure now opens the password prompt. Startup failures still release the busy state.
- Picker apply results use the same completion barrier; the regression checks that a specific stderr message survives a failed apply.
- Clipboard model rebuilds reveal the retained selection after layout. An 80-entry UI fixture verifies the selected row remains visible.
- Successful history refresh clears the previous error banner.
- Valid UTF-8 content without NUL bytes is copied as `text/plain;charset=utf-8`. Image MIME types are retained; other binary data remains byte-for-byte intact. Validation streams through the temporary file without allocating another full-size buffer.
- A failed automatic paste sends a notification and exits without reopening the popup or taking keyboard focus.
- Both autostart clipboard watchers now invoke `~/.scripts/clipboard-store.sh`. It skips sensitive/empty clipboard states and offers containing `x-kde-passwordManagerHint`; type-query failure also skips storage. This prevents future marked entries from being stored; it does not erase existing history.

## Theme engine and thumbnails

- All apply and `--install-matugen` operations take the same lock, covering generation, installation and reload. Listing and thumbnail generation use independent paths.
- `wallpaper_manager.py` and the other Python wallpaper entry points were checked: they classify/copy images and do not invoke Matugen. Their existing directory lock remains appropriate.
- Removed the duplicate wallpaper binary/source and legacy Rofi variants, including executable `.o` copies. Updated the affected Hyprland bindings. `wallpick.sh` and `theme.switcher.sh` remain compatibility launchers; image application routes through `theme.switcher --apply` with consistent Matugen options. The two old Hyprland image-switch scripts also use that entry point.
- One route table now handles presets, Matugen and Pywal, including the GTK fallback and optional Discord output. Removed the interactive Rofi implementation and unused helpers.
- Thumbnail workers read NUL-separated source/destination pairs from a temporary queue via `xargs -0 -a`; the command string no longer grows with the library.
- Cache filenames are SHA-256 hashes of path, nanosecond mtime and size. `--list-walls` supplies `path<TAB>thumbnail`, and QML no longer constructs cache names.
- `vipsthumbnail` creates 400-pixel-wide previews with four workers, one processing thread per worker, and reduced scheduling priority. The versioned cache prunes obsolete entries and abandoned partial files under its own lock. Old slash-to-plus JPEG cache files are retired too.
- Workers announce only successfully created previews. Cached tiles are no longer globally invalidated when opening the picker or when a no-op thumbnail job finishes.
- Pywal uses the same small cached input on cold and warm runs, avoiding both cache-dependent palettes and unnecessary full-resolution color extraction.
- Atomic copies resolve destination symlinks, preserve existing destination permissions, sync the temporary file before rename, and sync the parent directory afterwards. Installation preflights all sources and rolls back earlier replacements if a later write fails.
- Image extension normalization handles unsigned bytes safely. Wallpaper ordering uses nanosecond timestamps and a filename tiebreak.

## Quickshell and build cleanup

- A persistent `MusicService` singleton uses native MPRIS properties and methods. Closing a panel no longer discards player state. Removed `playerctl` polling, reconciliation polls and command processes from the widget. Player selection survives widget recreation; controls respect player capabilities.
- Replaced the continuously animated equalizer with a static playback symbol.
- Window titles are visible only on the focused monitor. Picker typography comes from the default profile's Theme.
- `run.sh` waits for `Configuration Loaded`, checks for process exit, and fails after a bounded ten-second startup timeout. It does not impose the old unconditional half-second delay.
- Deleted the stale root and `shared/` Colors files. Profile, clipboard and picker links continue to use `components/Colors.qml`.
- Added ignore rules for generated artifacts, removed obsolete artifacts, fixed the scripts Makefile, and added serialized on-demand theme-helper builds to its launchers. OpenSSL supplies hashing; libvips supplies thumbnail generation. Both are available on this machine.
- Seven generated paths in `~/dotfiles` were removed from the Git index. These deletions are staged; the active `theme.switcher`, scripts `sysmon`, and native `sysmon` executables remain on disk and are ignored. No commit or push was performed.
