# Notification stack and desktop-script fixes — 2026-10-08

Implemented and validated the supplied findings against the installed configuration.

- Popups now have three independent slots (maxVisible clamps to 1–3), a bounded
  queue, critical preemption, hover-paused timeouts and persistent-notification
  yielding. Replacements cancel pending removal and respect hover. Popup clicks,
  close buttons and the closeLatest IPC shortcut only hide popups. Drawer close
  and Clear still remove history. Notification actions retain their existing
  protocol behavior; the daemon had no extra action-dismissal or expiry timer.
- DND is controlled by the daemon, including its persistence setter, rather than
  a separately checkable button. The drawer always reserves scrollbar space.
- Theme reload is explicitly best-effort/void; impossible reload-error branches
  are gone. Wallpaper failure reporting remains. The rebuilt binary is installed.
- Native sysmon already exists, is newer than its source, and run.sh builds it
  via native/Makefile. Its path did not need changing.
- Live Hyprland reports blur as JSON bool, not int. The parser accepts either
  representation rather than replacing working boolean support with int-only.
- Audio mute toggles synchronously through wpctl before reading state/OSD/LED.
  Both audio scripts have explicit dependency guards; microphone LED support
  remains optional.
- Both animation menus now use one implementation, validate the selection,
  and update both links before reloading Hyprland.
- Legacy bar scripts route to the selected Quickshell profile first, with Waybar
  fallback. One shell-level IPC handler controls all bars. Manual visibility and
  fullscreen suppression are separate and survive hot reload; hiding closes the
  control panel. No polling process was added.
- Explicit Makefile dependency filenames match the include/clean rules. Removed
  the stale theme.d; -Werror is opt-in. Both build targets compiled successfully.
- WayClick freezes startup sound objects after loading, leaving collection on
  for later asyncio cycles. Signal-cleanup regressions still pass.
- Power-profile state is committed after CPU success, before optional GPU writes.
  GPU failures report partial success while preserving the actual CPU mode in
  the cache; failure to commit the cache attempts CPU rollback. The proposed ERR
  trap alone would not undo a CPU change. Existing graphical sudo authentication
  remains; no sudoers expansion is necessary.
- Current build artifacts were already ignored. Three legacy tracked binaries
  were removed from the Git index only; working copies remain. Extended ignore
  rules cover them and bytecode. Hygiene changes are staged, not committed.
- Weather reads WEATHER_LOCATION or ~/.config/weather-location. Migrated the
  existing value to the latter with mode 0600, updated both tracked script copies,
  and ignored that local setting. Existing Git history was not rewritten.

Validation: tests/run.py (both profiles), tests/popup_stack.py (8 cases),
tests/notifications.py (private D-Bus), tests/theme.py (isolated theme engine),
tests/scripts.py, tests/desktop_controls.py, tests/wayclick_cleanup.py, shell
syntax and embedded Python compilation. Desktop controls use mocked commands;
no live audio, power-mode, animation, or fullscreen changes were made. The active
bar hot-reloaded successfully and exposes the new IPC methods. Tests now isolate
the notification settings cache; the older test's DND cache change was restored.

Outside-workspace changes were checked against original hashes and installed
from /tmp/qs-oct08. Original files are backed up in /tmp/qs-oct08/originals.
