# Config and script review — 2026-10-05

Scope: Quickshell components, desktop integration in Hyprland, scripts in
`~/.scripts`, and GTK warnings observed in the running shell. This is a targeted
review, not an exhaustive audit of every configuration under `~/.config`.
No live configuration changes were made during this review.

## Confirmed findings

1. **Notification dismissal shortcut cannot locate the bar.**
   `~/.config/hypr/keybinds.lua:28` invokes
   `qs ipc call notifications closeLatest` without a configuration path.
   Running `qs ipc show` reports that the default configuration cannot be found.
   Explicitly selecting `~/.config/quickshell/profiles/alt` exposes the expected
   `notifications.closeLatest` handler. Resolve the selected bar profile using
   the existing shared script helpers and pass its directory through `-p`.

2. **Performance keyboard shortcut retains the authentication failure.**
   `~/.config/hypr/keybinds.lua:50` still calls
   `~/.scripts/toggle-performance.sh` directly. Its sudo calls have no graphical
   password helper. This is the same failure recorded in the panel logs before
   today's button fix. Route the shortcut through
   `~/.config/quickshell/native/toggle-performance.sh` as well. The failure is
   conditional on sudo requiring authentication; passwordless authorization
   would avoid it.

3. **Polkit autostart references a missing executable.**
   `~/.config/hypr/autostart.lua:10` starts
   `/usr/lib/polkit-kde-authentication-agent-1`, which is absent.
   `/usr/lib/hyprpolkitagent/hyprpolkitagent` is installed, as is its user service.
   Replace the obsolete startup entry with the installed agent's service,
   checking existing session service activation to avoid duplicate agents.
   This autostart entry definitely fails; whether another mechanism already
   provides a running authentication agent was not established.

4. **Animation picker accepts nonexistent selections and breaks its symlink.**
   `~/.scripts/animation.switcher.sh:12` replaces `animations.lua` without
   checking that the typed Rofi result names an available Lua file. In an
   isolated HOME with mocked desktop commands, selecting `MisspelledTheme`
   returned success and replaced the valid link with a dangling one. Restrict
   Rofi to listed choices and validate the selected file before replacing the
   link; only announce success after the change succeeds.

5. **GTK 4 theme imports are unresolved.**
   `~/.config/gtk-4.0/gtk.css:1` imports `libadwaita.css` and
   `libadwaita-tweaks.css`. The stylesheet is symlinked from the installed theme,
   but the imported files are missing alongside the config-side link. Actual
   Zenity logs report both missing files, so the theme is not fully applied.
   Both source files exist under
   `~/.local/share/themes/adw-gtk3-dark/gtk-4.0/`; provide corresponding config
   links without replacing the existing stylesheet or assets.
