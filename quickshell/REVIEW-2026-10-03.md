# Review findings and changes — 2026-10-03

Reviewed the twelve submitted findings against the live configuration and scripts.

1. **Wi-Fi stdin:** no dropped-write bug found. Quickshell calls QProcess.closeWriteChannel(), which drains queued writes before EOF. A delayed-reader check on the installed Quickshell received the complete 1 MiB payload after immediate stdin closure. The existing nmcli mock also receives the complete password. Actual wrong/right-password authentication was not tested against a live network.
2. **Brightness completion:** the upstream implementation emits exited before runningChanged, so the reported failure is not established. Nevertheless, completion now distinguishes a process that never started from one that exited and finalizes once, independently of that ordering.
3. **Scan notifications:** the live scan command uses `--rescan no`, not `--rescan yes`. The reported rescan-throttling trigger does not apply. Real errors remain visible.
4. **Drawer monitor:** fixed. Closing no longer clears the monitor until the drawer is hidden after its fade. Private notification tests cover retention and release.
5. **Clipboard paste without a target:** fixed. The error explains that no window was focused when the picker opened, rather than claiming the focus changed.
6. **Clipboard preview documentation:** corrected to describe 256 KiB inline images, larger-image thumbnails up to 1024×768, and the 512 KiB thumbnail limit before base64 encoding. Original copy bytes remain intact.
7. **Clipboard refresh:** inspecting the same ID preserves the current preview and pending request. Failed previews can still be retried.
8. **Music pages:** automatically remember the first visible player and adopt a replacement when it disappears. Reordering or a returning player no longer changes the selected player. One normal wheel notch advances one page; touchpad pixel deltas retain their own threshold.
9. **Bluetooth pairing:** added an on-demand helper using the installed Blueman authentication dialogs. Its agent is registered only for its own Pair call, without becoming the default agent. Trust and Connect follow successful pairing; cancellation/rejection do not trust the device. Confirmation dialogs bypass shell DND without changing user settings. Private fake BlueZ tests use the real agent with simulated dialog responses. Physical devices and real PIN entry remain untested.
10. **Picker profile state:** valid existing logic. `~/.scripts/quickshell-common.sh` writes `quickshell_current_bar`; the switching/autostart scripts use it.
11. **Older script findings:** fixed all three. WayClick terminates and waits for its tracked child on wrapper signals. Restore creates `~/.scripts` only if neither an existing entry nor a broken symlink is present. Wallpaper processing preflights managed directories and refuses symlinked theme/archive/backup folders or index files; curated image symlinks are preserved. The installer checked source hashes and retained originals under `/tmp/qs-review-fixes/`.
12. **Duplicate-bar scenario:** no change needed for the current startup path. Hyprland launches `quickshell-autostart.sh`, which stops known profile instances and starts through `run.sh`; it does not launch an unmanaged direct instance.

## Hover follow-up

The control panel input region stays below the bar during animation and includes the gap above the panel. The hover region now contains the controls, rather than being their sibling. This preserves hover tracking over interactive children. Returning to the clock cancels closing; returning during the fade reopens immediately. The requested final close grace period is **560 ms**. Pinned panels and password entry retain their existing close protections.
