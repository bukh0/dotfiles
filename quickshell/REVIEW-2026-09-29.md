Remaining findings and possible improvements, not changed in this pass:

- [WayClick signal cleanup](/home/bukh0/.scripts/wayclick/dusky_wayclick.sh:108): the INT/TERM handler only updates state and restores the cursor. A signal sent only to the wrapper can interrupt its `wait` while leaving the Python runner alive. Forward termination to the tracked child and wait for it before marking the service stopped.
- [Fresh-install restore](/home/bukh0/dotfiles/backup-dotfiles.sh:155): `--restore` does not create the `~/.scripts` symlink on a fresh installation. The current machine already has it; fresh-install handling should create it only when the destination is absent.
- [Multi-file theme transactions](/home/bukh0/.scripts/theme.switcher.cpp:181): each copy is atomic, but `--install-matugen` does not roll back earlier files if a later write fails. Concurrent theme changes also lack a shared transaction lock. The missing-output preflight fixes one cause of partial installation, not every possible cause.
- [Wallpaper directory containment](/home/bukh0/.scripts/wallpaper_tools.py:317): checking the final file for symlinks does not prevent writes or archival through a symlinked theme directory. Resolve and validate managed destination parents if theme folders may be symlinks.
- [Music polling](/home/bukh0/.config/quickshell/components/MusicWidget.qml:120): the panel still invokes `playerctl` every two seconds while visible. Native MPRIS bindings, already used by the clock, could remove that process overhead. This needs a separate UI/integration change.
